# CampusRun v0.1.1 · Windows 测试版

东北大学“校园乐跑”只读查询与配速规划工具，Windows 桌面测试版。

## 本次更新

- **自动 UAC 提权**：启动时如果当前不是管理员，会自动请求管理员权限，
  避免 `%APPDATA%\CampusRun` 写入被拒绝导致的“刷新失败”。
- **缓存/会话写入容错**：即使缓存或 `sports_session.dat` 写入失败，
  本次读取的数据仍会正常显示，不再弹“刷新失败”。
- **首次使用指南**：第一次启动显示 4 页简短引导（登录、目标、查看结果）；
  不含抓包内容。点“开始使用”后只显示一次，可从“抓包帮助 → 使用指南”重开。
- 页面/文档同步到 0.1.1。
