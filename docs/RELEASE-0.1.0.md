# CampusRun v0.1.0 · Windows 首个发行版

东北大学“校园乐跑”只读查询与配速规划工具，Windows 桌面版。

> **非学校官方工具**。本项目由 AI 编程助手生成或辅助生成，仅供学习与技术练习；
> 禁止代跑、刷里程、伪造记录或学术不端。代码以 MIT License 开源。

## 下载

- `CampusRun-0.1.0-win64.zip`
- SHA256：`AE6D3B469D5A8B3B1306DA2F2E1C363A39A617041BA4AFED8BA71BBA0F65EE1A`

解压后双击 `CampusRun.exe` 即可，不需要安装 Python。
请保留 `_internal` 文件夹，不要只复制 exe。

## 功能

- 学号/密码登录学校统一身份认证，读取校园乐跑次数、公里和记录；
- 支持短信二次认证、会话过期自动重登；
- 首次绑定邮箱页面可点“稍后绑定”跳过；
- 目标 km / 截止日期 / 每周休息日自定义；
- 每天 2/3/4/5 km 完成天数、预计完成日期、逐日计划；
- 记录查看与 CSV 导出；
- 演示模式；
- 首次启动弹出简短使用指南（登录、目标、查看结果），不包含抓包内容；
- 抓包 cURL 备用方式（默认隐藏，账号登录连续失败 2 次后出现）。

## 安装与使用

1. 解压 zip 到任意目录；
2. 双击 `CampusRun.exe`；
3. “连接设置 → ① 账号登录”，输入学号/密码；
4. 需要短信时输入验证码；首次绑定邮箱可点“稍后绑定”；
5. 回到概览设置目标与截止日期。

详细说明见包内 `README.md` 和 `CAPTURE.md`。

## 隐私

- 密码/会话/抓包凭据只用 Windows DPAPI 加密保存在本机；
- 只读接口，不提交跑步、不修改成绩；
- 不上传任何数据；导出 CSV 不含 token。

## 已知限制
